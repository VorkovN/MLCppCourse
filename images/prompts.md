# Промпты для генерации изображений к темам курса

---

## 1. OpenCV — Детекция окружностей

**Промпт для генерации**:
```
Создай скриншот-стиль изображения: кадр с камеры, на котором видны несколько округлых объектов (монеты, шары, тарелки). 

На изображении должны быть:
- Синие окружности, обведённые вокруг найденных объектов (толщина линии 2-3px)
- Красная точка в центре самой большой окружности
- Несколько окружностей разного размера
- Естественное освещение, реалистичный вид кадра с камеры

Стиль: Фотореалистичный, как будто скриншот с веб-камеры. Разрешение 1280x720. Нейтральный фон.
```

---

## 2. MediaPipe — Face Landmarks (478 точек)

**Промпт для генерации**:
```
Создай визуализацию face mesh с 478 точками на лице человека. 

На изображении должно быть:
- Портрет человека (анфас, хорошее освещение)
- Сетка из точек, соединённых тонкими линиями (face mesh)
- 478 точек, равномерно распределённых по лицу
- Особенно чётко видны точки вокруг глаз, носа, рта, контура лица
- Зелёные точки и тонкие зелёные линии для mesh
- Фон нейтральный, тёмный

Стиль: Техническая визуализация, похожая на документацию MediaPipe. Чистый, профессиональный вид.
```

---

## 3. YOLO — Детекция объектов

**Промпт для генерации**:
```
Создай изображение с результатом детекции объектов YOLO. 

На изображении должно быть:
- Уличная сцена или интерьер с людьми, машинами, велосипедами, сумками
- Цветные прямоугольники (bounding boxes) вокруг каждого обнаруженного объекта
- Разные цвета для разных классов (например, синий для person, красный для car, зелёный для bicycle)
- Подписи с классами и confidence scores в формате "person 0.95", "car 0.87", "backpack 0.82"
- Шрифт моноширинный, читаемый, белый с чёрной обводкой
- Несколько объектов разных размеров

Стиль: Фотореалистичное изображение с наложенными техническими аннотациями. Яркие, контрастные цвета для boxes.
```

---

## 4. OCR — Распознавание текста

**Промпт для генерации**:
```
Создай коллаж из двух частей, показывающий работу OCR. 

Левая часть (до обработки):
- Изображение документа или скриншота с текстом
- Может быть немного размыто, неидеальное качество
- Текст на русском и английском языках
- Подпись "Исходное изображение"

Правая часть (после OCR):
- То же изображение, но с выделенными областями текста (цветные прямоугольники)
- Распознанный текст показан рядом или под выделенными областями
- Confidence scores для некоторых слов (например, "95%", "87%")
- Подпись "Результат OCR"

Стиль: Техническая документация, чистое оформление. Разделительная линия между частями. Белый фон.
```
