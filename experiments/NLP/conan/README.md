**Команды для конан:**
* Добавить удаленный репозиторий: ` conan remote add gitlab https://gitlab.axoning.com/api/v4/projects/23/packages/conan`
* Авторизоваться в артифактори: `conan remote login gitlab <логин> -p <пароль>`
* Собрать пакет (из корня пакета): `conan create . --build=missing  --profile:build ../profile_release  --profile:host ../profile_release`
* Обновить пакет в артифактори: `conan upload "*" -r=gitlab`
* Стянуть зависимости (из корня проекта): `conan install ./conan/conanfile.txt --output-folder=<папка для сборки> --build=missing --profile:build <путь до профиля>  --profile:host <путь до профиля>`
  * `conan install ./conan/conanfile.txt  --output-folder=build --build=missing  --profile:build conan/profile_macos_release  --profile:host conan/profile_macos_release`
* Удалить все пакеты: ` conan remove "*" -c`

**Краткий гайд по conan**
* Conan - пакетный менеджер(как pip или npm)
* В конан присутствуют не все необходимые библиотеки, для написания своей библиотеки для конан необходимо написать рецепт(файл с описанием сборки пакета)
* Из conan репозитория можно скачать уже собранную библиотеку или рецепт
* Чтобы конан понимал под какую платформу нужно собрать библиотеку при создании пакета и при скачивании удаленных пакетов указывается путь для профиля(файл с описанием платформы)
* Указывается 2 профиля: платформа **на** которой собирается библиотека и платформа **для** которой собирается библиотека
* Для команды скачивания библиотек необходимо указать файл: [conanfile.txt](conanfile.txt), в нем прописаны все необходимые версии
* При сборке пакета версия собираемого пакета указывается в рецепте
* При запуске команды install генерируется conan_toolchain.cmake, который содержит информацию о всех путях к либам, потому его необходимо заинклюдить в корневом Cmake
* В папке юзернейм/.conan хранятся все либы и при желании можно отыскать любую собранную интересующую библиотеку там
